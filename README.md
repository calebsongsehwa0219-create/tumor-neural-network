# 인공신경망을 활용한 종양 데이터 분류

## 프로젝트 소개
scikit-learn에 포함된 유방 종양 공개 데이터셋을 사용해 다층 퍼셉트론(MLP) 인공신경망을 학습하고, 서로 다른 은닉층 구조의 분류 성능을 비교하는 교육용 프로그램입니다.

## 연구 질문
인공신경망의 은닉층 구조에 따라 분류 정확도와 악성 재현율은 어떻게 달라지는가?

## 실행 방법
1. Python 3가 설치되어 있는지 확인합니다.
2. 터미널/명령 프롬프트에서 아래 명령어를 실행합니다.

```bash
pip install scikit-learn pandas matplotlib
```

3. `tumor_classifier.py`를 실행합니다.

```bash
python tumor_classifier.py
```

## 실험 설계
- 독립변인: 은닉층 구조와 뉴런 수
- 종속변인: 정확도, 악성 재현율
- 통제 조건: 동일한 데이터 분할, 전처리, 난수 설정 및 평가 데이터
- 모델: (8,), (16,), (16, 8) 구조의 MLP

## 평가 지표
- 정확도: 전체 평가 데이터 중 올바르게 분류한 비율
- 악성 재현율: 실제 악성 데이터 중 악성으로 올바르게 분류한 비율
- 혼동 행렬: 실제 분류와 예측 분류를 비교한 표

## 한계 및 주의
이 프로젝트는 교육과 실험을 위한 공개 데이터 분석입니다. 실제 환자의 진단이나 치료 판단에 사용할 수 없습니다. 세 모델은 은닉층 구조와 뉴런 수가 함께 달라지므로, 성능 차이를 은닉층 개수 하나의 영향으로만 단정할 수 없습니다.
